# ULCARE Streamlit

Versi Streamlit ini memuat `ulcare_interface.html` sebagai kanvas antarmuka. Dengan cara ini, tampilan dan interaksi tetap sama seperti versi HTML asli: dashboard, AI Scan Tool, tab Edukasi, tab TIM WISPO 3, pemilih bahasa, upload foto, Grad-CAM, modal email, dan print/download.

## Struktur repository

- `app.py` — entry point Streamlit
- `ulcare_interface.html` — antarmuka penuh
- `model_gangren_wagner_v1.h5` — model yang disediakan
- `requirements.txt` — dependensi deployment

## Deployment

Di Streamlit Community Cloud, pilih `app.py` sebagai Main file path.
